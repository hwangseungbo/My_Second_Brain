# My Second Brain

LLM이 유지보수하는 개인 지식 베이스. 소스를 넣으면 LLM이 읽고, 요약하고, 교차 참조하고, 위키를 만들어줍니다.

## 왜 만들었나

대부분의 LLM + 문서 경험은 RAG입니다. 파일을 올리면 질문할 때마다 관련 조각을 검색해서 답변을 생성합니다. 작동은 하지만, **지식이 축적되지 않습니다.** 다섯 개의 문서를 종합해야 하는 질문을 하면 매번 처음부터 조각을 찾아 맞춰야 합니다.

이 프로젝트는 다릅니다. LLM이 소스를 읽고 **영구적인 위키**를 점진적으로 구축합니다. 교차 참조는 이미 만들어져 있고, 모순은 이미 표시되어 있고, 종합은 읽은 모든 것을 반영합니다. 소스를 추가할수록 위키는 더 풍부해집니다.

> Vannevar Bush의 Memex(1945) 비전에 가깝습니다 — 문서 간 연결이 문서 자체만큼 가치 있는, 능동적으로 큐레이션되는 개인 지식 저장소. Bush가 해결하지 못한 부분은 유지보수였고, LLM이 그 역할을 합니다.

## 구조

```
My_Second_Brain/
  CLAUDE.md          # 스키마 — LLM이 따르는 규칙과 워크플로우
  raw/               # 원본 소스 (PDF, 마크다운 등) — 수정 불가
    assets/          # 소스에 포함된 이미지, 첨부파일
  wiki/              # LLM이 생성하고 유지하는 위키
    index.md         # 전체 페이지 목록
    log.md           # 작업 기록 (시간순)
    sources/         # 소스별 요약 페이지
    entities/        # 인물, 조직, 장소
    concepts/        # 개념, 이론, 기법
    topics/          # 여러 소스를 종합하는 주제 페이지
    comparisons/     # 비교 분석
    meta/            # 모순 추적, 위키 건강 상태
```

## 사용법

### 준비물

- [Obsidian](https://obsidian.md/) — 위키 브라우저 (그래프 뷰로 연결 시각화)
- [Claude Code](https://claude.ai/claude-code) — LLM 에이전트 (위키 유지보수 담당)

### 핵심 워크플로우

**1. 수집 (Ingest)**

`raw/` 폴더에 소스를 넣고 에이전트에게 수집을 요청합니다.

```
> raw/에 논문 넣었어. 수집해줘
```

LLM이 소스를 읽고, 요약 페이지를 만들고, 관련 개념/엔티티 페이지를 생성하거나 업데이트하고, 인덱스와 로그를 갱신합니다. 하나의 소스가 10~15개 페이지에 영향을 줄 수 있습니다.

**2. 질문 (Query)**

위키에 대해 질문합니다. LLM이 인덱스에서 관련 페이지를 찾아 인용과 함께 답변합니다.

```
> RAG의 한계가 뭐야?
> Doc-to-LoRA랑 Lost in the Middle 논문의 관계가 뭐야?
```

유의미한 답변은 위키에 새 페이지로 저장할 수 있습니다.

**3. 점검 (Lint)**

위키 건강 상태를 점검합니다.

```
> 위키 점검해줘
```

고아 페이지, 모순, 누락된 링크, 빈약한 주제, 새로 조사할 질문 등을 찾아줍니다.

## 활용 예시

| 분야 | 설명 |
|------|------|
| **연구** | 논문, 기사를 수집하며 진화하는 종합 위키 구축 |
| **독서** | 챕터별 수집, 인물/테마/줄거리 페이지 자동 생성 |
| **자기개발** | 저널, 기사, 팟캐스트 노트를 구조화된 자기 이해로 |
| **업무** | 회의록, 슬랙 스레드, 고객 통화를 정리된 내부 위키로 |
| **취미** | 관심 분야 딥다이브 — 지식이 흩어지지 않고 조직됨 |

## 원칙

- **위키가 산출물이다** — 채팅이 아니라 위키에 지식이 축적됩니다
- **소스는 불변이다** — `raw/`의 원본은 절대 수정하지 않습니다
- **연결이 복리로 쌓인다** — 새 소스마다 기존 페이지들이 더 풍부해집니다
- **모순은 기능이다** — 숨기지 않고 명시적으로 추적합니다
- **사람이 방향을 잡고, LLM이 유지보수한다** — 당신은 큐레이터, LLM은 사서입니다

## 팁

- **Obsidian Web Clipper**로 웹 기사를 마크다운으로 클리핑하여 `raw/`에 저장
- **그래프 뷰**로 페이지 간 연결을 시각적으로 탐색
- **Dataview 플러그인**으로 프론트매터 기반 동적 테이블 생성
- **Marp 플러그인**으로 위키 내용을 슬라이드로 변환
